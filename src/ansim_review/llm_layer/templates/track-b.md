# Track B — Independent Audit

Audit every Track A claim ID exactly once. Do not rewrite Track A and do not
set confidence, abstention, final status, or a human decision.

Allowed dispositions: `ACCEPT`, `REJECT`, `INCOMPLETE`.
Allowed finding codes: `MISSING_EXCEPTION`, `CITATION_MISMATCH`,
`UNSUPPORTED_CLAIM`, `CALCULATION_MISMATCH`, `RULE_STATUS_MISMATCH`,
`FINAL_DECISION_LANGUAGE`, `SOURCE_CONFLICT`.
