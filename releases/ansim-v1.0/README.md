# Ansim v1.0 release gate

Use `scripts/build_ansim_release.py` to produce deterministic candidate artifacts. The repository does not contain a signed `acceptance-record.json`; therefore no `ansim-v1.0` tag may be created yet. A named reviewer must complete `docs/acceptance/ANSIM_ACCEPTANCE_CHECKLIST.md`, sign the exact candidate and packet hashes, and rerun the release builder.
